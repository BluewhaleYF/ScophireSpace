# 平阳话里的“我”和“我们”

平阳话属于**浙南闽语**，主要分布于浙南一带，在浙江台州玉环也有分布。本文所使用的平阳话语料，收集于**浙江省台州市玉环市大麦屿**。

最近比较平阳话和厦门话时，我注意到了一组比较明显的区别：

| 概念 | 厦门话 | 平阳话 |
| :--- | :--- | :--- |
| **我** | *guá* | **wá** |
| **阮（排除式“我们”）** | *gún / guán* | **wén** |
| **咱（包含式“我们”）** | *lán* | **lán** |

厦门话的 *guá* 和 *gún* 都以 **g-** 开头，听感比较接近，需要结合韵母和上下文进行判断。

平阳话则是 **wá / wén**。“我”的声母发生了明显变化，但两个词的韵母区别也更加突出，因此在实际听辨中，我认为反而更容易区分。

从这个角度看，平阳话的音变虽然发生得更明显，却没有让词语变得更难辨认，反而拉开了“我”和“阮”之间的语音距离。

当然，这里的“更容易区分”只是针对这组词的现代语音听感。至于这些读音与历史闽南语之间的具体关系，以及 *g → w* 等变化的历史过程，还需要结合更多浙南闽语方言点和历史音韵资料进行判断。
