# 浙南闽语杂谈

浙江南部整体处于吴语区，但在温州南部、台州南部沿海，却分布着一片闽语区，即**浙南闽语**。这种“吴语区中夹着闽语”的格局，与历史上的福建移民有很深的关系。

历史上福建沿海居民不断向浙南迁徙，明清时期尤为明显。来自泉州、漳州等地的移民进入平阳、瑞安、乐清、玉环等地，逐渐形成了今天的浙南闽语区。部分移民后来还继续向浙江北部迁徙，在吴语地区留下了一些闽语方言岛。

笔者本人是**浙江台州玉环人**，父亲来自大麦屿，母亲来自坎门。笔者从小主要在祖母家生活，因此最熟悉的是**大麦屿腔**，同时也能够使用和理解坎门腔。

家族口述和族源资料显示，笔者祖上在清朝康熙年间自福建泉州迁至玉环坎门。这一具体家族迁徙经历，也与玉环当地闽语区的历史来源相互印证。当然，单一家族的迁徙记录不能代表整个玉环地区的人口来源，只能作为当地移民史的一个具体例证。

本文所说的“平阳话”，属于浙南闽语的一部分；实际比较时，则主要以**泉州话与玉环腔浙南闽语**为对象。前者可以看作历史来源之一，后者则是在长期迁徙、地域隔离以及与吴语接触之后形成的地方变体。

玉环内部的闽语也并不完全一致。坎门过去对外交通相对封闭，因此保留了一些比较早的闽南语词汇。例如“地面”一类的表达，坎门仍有说 **“土跤”** 的传统用法，与福建闽南语的“塗跤” *thôo-kha* 相近。

大麦屿则由于对外交流更加频繁，与周边吴语接触也更密切，在词汇上出现了一些细微变化。例如笔者所熟悉的大麦屿腔，“地面”读作 `ka dau`，其正字目前尚无定论，笔者暂拟作 **「骹到」**。甚至一些吴语表达也进入了当地日常口语，例如吴语脏话 **“呆大”**，如今已经成为大麦屿一带较常见的口头表达。

除了词汇差异，我还注意到了“我”和“阮”的一组语音差别：

| 概念 | 泉州话 / 厦门话 | 玉环腔浙南闽语 |
| :--- | :--- | :--- |
| **我** | *guá* | **wá** |
| **阮（排除式“我们”）** | *gún / guán* | **wén** |
| **咱（包含式“我们”）** | *lán* | **lán** |

厦门话的 *guá* 和 *gún* 都以 **g-** 开头，听感比较接近，需要结合韵母和上下文判断。

玉环腔则是 **wá / wén**。“我”的声母发生了明显变化，但两个词的韵母区别也更加突出，因此在实际听辨中，我认为反而更容易区分。

从这个角度来看，玉环腔的音变虽然发生得更加明显，却没有让这两个词变得难以辨认，反而拉开了“我”和“阮”之间的语音距离。

当然，这里的“更容易区分”只是针对现代语音的听感。至于这些读音与历史闽南语之间的具体关系，以及 *g → w*、“骹到”等形式究竟经历了怎样的历史演变，还需要结合更多浙南闽语方言点、泉州及漳州方言材料和历史音韵资料进一步判断。

浙南闽语本身就是一个很适合观察语言接触与音变的区域：它一方面保留着来自福建的闽南语成分，另一方面又长期处于吴语环境之中。玉环内部不同聚落之间的差异，也让这种变化变得更加具体。
