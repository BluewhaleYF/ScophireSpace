本站友链遵循友好原则，旨在与独立博客建立基于内容认同的互联关系。友链交换以双方自愿、互相尊重为基础。

## 基本原则

1.  站点性质：个人独立博客，内容以原创为主，非商业性站点。
2.  访问要求：网站可正常访问，并已启用 HTTPS 协议。
3.  更新频率：站点在过去一年内有内容更新记录。
4.  互相认可：申请方已了解本站内容定位，并认可此友链说明。

---

## 关于友链的一点说明

个人博客的友链于我而言，更倾向于一种基于真实阅读和自然交流的连结。因此，我更希望在彼此有一定了解之后再建立链接——或许是通过几篇文章的往来阅读，或许是通过邮件或评论有过交流。这并非刻意设置门槛，而是认为友链应当承载一些真实的联结感。

## 单向添加

如果你希望在贵站添加本站的友链，**可以直接添加，无需事先征得同意**。但出于礼貌和互联的诚意，请在添加后发送邮件至 `scophire@proton.me` 告知贵站 URL，以便我知道并有机会回访。

## 添加本站友链

若需添加本站为友链，可根据贵站实际格式选择以下方式之一。

**方式一：快速复制 JSON 格式模板（适用于 Mizuki 主题）**
```
{
    id: 1,
    title: "ScophireSpace",
    imgurl: "https://raw.githubusercontent.com/BluewhaleYF/ScophireSpace/refs/heads/master/public/favicon/icon.png",
    desc: "Flint Scophire的个人博客",
    siteurl: "https://blog.scophire.space/",
    tags: ["Friends", "Blog"],
},
```

**方式二：按站点信息表格手动添加（适用于其它）**

| 项目 | 内容 |
| :--- | :--- |
| 站点名称 | ScophireSpace |
| 站点简介 | Flint Scophire的个人博客 |
| 站点地址 | https://blog.scophire.space/ |
| 站点图标 | https://raw.githubusercontent.com/BluewhaleYF/ScophireSpace/refs/heads/master/public/favicon/icon.png |

## 申请方式

请通过邮件联系：[scophire@proton.me](mailto://scophire@proton.me)

邮件中请提供以下信息：

- 博客名称及网址
- 博客简介（一两句话）
- 已添加本站友链的页面链接

我会在收到邮件后访问贵站并了解内容，若觉得合适，将在本站添加友链。无论是否添加，均会邮件回复告知结果。
