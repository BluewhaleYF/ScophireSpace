# 初识 COSMIC

看了 LTT 的视频才了解到了 Pop!_OS 及其桌面环境，当时就被它那种融合了平铺窗口与现代简约美学的设计风格吸引了。不得不说这是继 GTK 和 MD3 之后再一次打动我的风格。

![image](https://raw.githubusercontent.com/BluewhaleYF/ScophireSpace-Files/refs/heads/main/Posts/6/COSMIC%20official%20demo.webp)

长期以来我自己一直有一个思考，就是现在 Linux 貌似缺少一个真正适合大众的平铺式 DE，已有的 Hyprland 和 Niri 配置过于复杂，COSMIC 正好戳中了这个市场，给我这种没能力折腾配置文件的人一个体验平铺式的机会。

昨天晚上终于忍不住，在自己的 MacBook Pro 2014 上装了一套试试看。这篇文章没有做什么严谨测试，也不会去跑各种 Benchmark，只记录第一天使用下来最直观的一些感受。

![image](https://raw.githubusercontent.com/BluewhaleYF/ScophireSpace-Files/refs/heads/main/Posts/6/COSMIC.JPG)

# 测试环境

为了避免不同硬件之间产生较大的误差，先简单说明一下本次体验的环境。

| 项目 | 配置 |
| ---- | ---- |
| 设备 | MacBook Pro (Retina, 13-inch, Late 2013 / Mid 2014) |
| CPU | Intel Core i5-4308U（2C4T，最高 3.30 GHz） |
| GPU | Intel Haswell-ULT Integrated Graphics |
| 内存 | 8 GB LPDDR3 |
| 存储 | 512 GB SSD（btrfs） |
| 系统 | CachyOS |
| 内核 | Linux 6.18.40-1-cachyos-lts |
| 原桌面环境 | GNOME 50.3（Wayland） |
| 测试桌面 | COSMIC |
| 屏幕 | 2560 × 1600 Retina，60 Hz |
| 显示缩放 | 166.67%（非整数缩放） |


# 流畅度令人失望

安装速度非常快，最简包用 pacman 安装 5 分钟就搞定。

满怀希望重启切到 COSMIC 之后却有点傻眼。

第一感受就是卡，任何事即使不开任何美化，都奇卡无比，比公认占资源的 GNOME 还要卡得多，属于鼠标指针都掉帧的那种，完全不能用。当然考虑到 COSMIC目前仍处于开发阶段，基于 Rust 和 Iced 的渲染管线还没对这块 Intel Haswell-ULT 老集显好好优化，倒也意料之内。

想起几天前在 KVM/QEMU 里装 Pop!_OS 虚拟机，主力机 13 代低压 i7-1360P 分配了豪华 10 核 8G 内存，一样卡到窗口撕裂得乱七八糟，不过这也可能是 VirGL/SPICE 对 Iced 合成器兼容性不佳的问题。

# 一点简单的优化尝试

后来折腾了一会，体验稍微好了那么一点。

这台 MacBook Pro 配备的是 Haswell 核显，却要驱动一块 2560×1600 的 Retina 屏幕。我日常为了兼顾显示面积和字体大小，一直使用 166.67% 非整数缩放。显示效果和流畅度都比较理想。

不过切换到 COSMIC 后，系统并没有提供这一档缩放比例，自动改成了 175%，因此 GPU 的负担也进一步增加了。

GNOME 对这种场景已经优化得比较成熟，而 COSMIC 目前显然还有不少工作要做，因此老机器上的掉帧会更加明显。

查了一些资料之后，我尝试开启了 Intel i915 驱动的两个特性。

```bash
sudo nano /etc/modprobe.d/i915.conf
```

写入：

```text
options i915 enable_psr=2 enable_fbc=1
```

其中：

- `enable_psr=2`：启用 Panel Self Refresh（PSR）
- `enable_fbc=1`：启用 Framebuffer Compression（FBC）

重启之后，虽然距离流畅还有一段距离，但鼠标移动和窗口动画多少顺了一些，至少没有最开始那么难以使用。

当然，这更像是一种"缓解"，并没有从根本上解决 COSMIC 当前在 Haswell 核显上的性能问题。

# 本地化与视觉体验

接着是奇怪的中文本地化，系统界面巨量的元素缺乏汉化，有些已经翻译了的质量也参差不齐。更别提老生常谈的字体回退，一句话能给你用上五种字体，汉字粗细、有无衬线混在一起极为难受。好在手动去设置里强制切成 Noto Sans CJK SC 之后，视觉上基本能接受。

图标绘制也是丑出了自己的风格，和 Breeze 坐一桌，毫无和谐感。图标这块我还是力挺 Adwaita，真耐看。当然审美这东西比较主观，因人而异。

# 总结

总体来说，我不会因为第一次体验就轻易给 COSMIC 下结论。毕竟这是一个非常年轻的 DE，优化还需要时间。对 System76 后续打磨保持乐观，毕竟交互理念和配置逻辑确实切中了我日常需求，假以时日，COSMIC 完全有潜力成为主力DE。

目前我肯定还不会把 COSMIC 当作日常主力桌面，至少这台 Haswell 老机器暂时驾驭不了它。

不过我还是会继续关注这个项目。它现在暴露出来的大多数问题，都属于一个年轻桌面环境成长过程中很容易遇到的事情；真正吸引我的那套交互思路和设计理念并没有因此打折扣。等性能和细节慢慢打磨成熟之后，我很愿意再回来试一次。
